Firebase Setup

Enable Firebase for real sign-in

  1. Open your Firebase console and enable Authentication → Email/Password.
  2. Your Firestore database is already running in production mode, so you can use it directly.
  3. Create a collection called users.
  4. Create a document for each account using the Firebase UID as the document ID and a field: role = student or tutor.
  5. Create two Firestore collections: dashboardData and tutorDashboardData, each with a document named main.

After that, sign in through the student or tutor login links and the dashboard will load the real Firestore-backed data.
